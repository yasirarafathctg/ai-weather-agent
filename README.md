## 📌 About The Project

AI Weather Agent is an intelligent weather information assistant designed to retrieve weather-related information and provide automated responses.

This project demonstrates how AI agents, API integrations, and workflow automation can work together to build an intelligent assistant.

The workflow is developed using n8n to demonstrate practical AI automation and agent development.

### How to Import

1. Download the JSON workflow file.
2. Open your n8n dashboard.
3. Select Import from File.
4. Choose the downloaded JSON file.
5. Configure the required API credentials.
6. Test the workflow.

## 🚀 Getting Started

1. Clone this repository.
2. Download the workflow JSON.
3. Import it into n8n.
4. Configure the required API credentials.
5. Execute and test the workflow.
